## Formatting

```bash
just format    # biome + prettier + shfmt across the repo
```

## Commits

Commits follow [Conventional Commits](https://www.conventionalcommits.org). The
`commit-msg` hook enforces it. See [Git Workflow](/git/workflow/#commit-messages).

## CI

- **shellcheck** on every shell script
- A scripts sanity check
- Tagging `vX.Y.Z` cuts a GitHub release, with notes generated by
  [git-cliff](https://git-cliff.org), and refreshes `CHANGELOG.md`
- The repository is mirrored to GitLab
- Changes under `docs/` rebuild and deploy this site to GitHub Pages

## Working on the docs

The docs site is built with [Astro](https://astro.build) and
[Starlight](https://starlight.astro.build). Everything, including
`package.json`, lives in `docs/`. Pages are Markdown (or MDX) files in
`docs/src/content/docs/`:

```bash
cd ~/dotfiles/docs
pnpm install
pnpm docs:dev       # live preview
pnpm docs:build     # production build, fails on dead links
pnpm docs:preview   # serve the production build locally
```

To add a page, create a Markdown file under `docs/src/content/docs/` with a
`title` in its frontmatter and add it to the `sidebar` in
`docs/astro.config.mjs`. Link to other pages with root-relative paths such as
`/guide/stow/`, the site's base path is added automatically.

Colour palettes live in `docs/src/styles/palettes.css`, and the assistants in
the "Copy page" menu are listed in `docs/src/lib/ai-targets.ts`.
